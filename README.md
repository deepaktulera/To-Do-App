# 📝 To-Do App

A simple and responsive To-Do web application built using **React** and **Tailwind CSS**.

## ✨ Features

- ➕ Add new tasks
- ✏️ Modify existing tasks
- ❌ Delete tasks
- ✅ Mark tasks as completed or pending
- 📱 Responsive UI

---

## 🚀 Tech Stack

- React
- Tailwind CSS
- JavaScript

---

## 📂 Installation

Clone the repository and install dependencies.

```bash
git clone <your-repository-url>
cd To-Do WEB-APP
npm install
npm run dev
